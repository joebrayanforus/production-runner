# Labyrinthes du Production Runner

Le jeu comporte maintenant **4 labyrinthes différents** avec des thèmes industriels distincts, qui changent automatiquement à chaque niveau.

## 🏭 MAP 1: Classic Industrial Factory
**Caractéristiques:**
- Layout équilibré avec de nombreux couloirs
- Zones centrales ouvertes pour l'action
- Multiples voies d'évacuation
- Difficulté: ⭐⭐ Moyenne

**Stratégie:**
- Utiliser les tunnels latéraux pour échapper
- Les coins supérieurs offrent des zones de sécurité
- Centre du labyrinthe = zone à haut risque

---

## 🔧 MAP 2: Production Line Maze
**Caractéristiques:**
- Design inspiré d'une chaîne de production
- Longs couloirs horizontaux
- Zones étroites nécessitant précision
- Difficulté: ⭐⭐⭐ Difficile

**Stratégie:**
- Éviter de rester dans les longs couloirs
- Utiliser les jonctions pour piéger les malfunctions
- Les stations de maintenance dans les coins sont cruciales

---

## ⚙️ MAP 3: Assembly Hub
**Caractéristiques:**
- Design circulaire/radial
- Hub central avec connections multiples
- Symmetrie facilitant l'orientation
- Difficulté: ⭐⭐ Moyenne-Facile

**Stratégie:**
- Le centre offre plusieurs échappatoires
- Circuit extérieur pour collecter en sécurité
- Malfunctions prévisibles grâce à la symétrie

---

## 🎯 MAP 4: Quality Control Center
**Caractéristiques:**
- Labyrinthe complexe et compact
- Nombreux culs-de-sac
- Zones de contrôle qualité (checkpoints)
- Difficulté: ⭐⭐⭐⭐ Très Difficile

**Stratégie:**
- Mémoriser les impasses pour éviter les pièges
- Planifier les routes à l'avance
- Les tunnels sont vitaux pour la survie

---

## 🎮 Progression des Maps

Le jeu alterne entre les 4 maps selon le niveau:
- **Niveau 1**: Factory
- **Niveau 2**: Production Line
- **Niveau 3**: Assembly Hub
- **Niveau 4**: Quality Control
- **Niveau 5**: Factory (cycle recommence avec difficulté accrue)
- etc.
